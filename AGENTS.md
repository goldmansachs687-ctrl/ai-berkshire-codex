# Publishing and research language / 发布与研究语言

- Update English and Simplified Chinese together in the same commit for every reader-facing GitHub change. Keep navigation, examples, facts, version numbers, commands, and verification limits aligned across languages.
- Route research by intent in both languages. An equivalent request gets the same scope, evidence standards, research roles, valuation method selection and review criteria. Follow the requested output language, otherwise the language of the request. Pass it to all workers and retain verbatim source quotations.
- Verify both language versions before publishing. In the two plugin entrypoints, keep matching English and Chinese examples for full research and focused questions.

- 每次改动面向读者的 GitHub 页面，中英文必须在同一次提交更新。导航、示例、事实、版本号、命令和验收边界保持对应。
- 两种语言均按意图路由。等价请求使用相同的任务范围、取证标准、研究角色、估值方法选择和复核条件。优先使用用户指定的输出语言，否则沿用提问语言。将语言传给所有角色，原文引语保持原样。
- 发布前核对两种语言。两个插件入口均保留完整研究和专项问题的成对示例。
