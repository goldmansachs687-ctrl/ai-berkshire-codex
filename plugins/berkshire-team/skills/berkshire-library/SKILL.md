# 伯克希尔投资资料库

用户要求添加/整理材料时执行。工具在 `../berkshire-team/scripts/knowledge.py`，规范在 `../berkshire-team/references/knowledge.md`，先读取规范。默认用户工作区 `knowledge/berkshire/`；用户指定路径优先。不要把用户资料写进插件安装缓存或发布包。

只处理用户给出的材料/路径或明确要求获取的公开来源，不扫描无关私人目录。已有文件立即登记；尚无文件时可以建立待读目录，说明缺失的具体材料，不声称已经读过。查询可使用本地search，无需外部数据库或上传。

1. 标识书名/作者/版本/日期；个人笔记与原文分开。PDF/OCR及EPUB解析使用当前可用技能或工具，保留页码/章节/时间戳，无法提取则仅登记。
2. `knowledge.py --library <库> add --file <文件> --title <标题> --kind <book/letter/transcript/note> [--text-file <提取文本>] [--url <原始链接>]`。
3. 搜索：`knowledge.py --library <库> search --query <关键词>`。这是逐行字面检索；中文可先用短关键词，未命中不代表概念不存在。读取命中上下文再引用。
4. 真正读完选定段落后：`knowledge.py --library <库> review --id <材料ID> --locator <章节/页码> --note <阅读结论>`。只记读过的范围，不自动标全书完成。
5. 提炼principles.md：出处、作者原意、我们的操作规则、适用条件、反例、缺证据处理、验证案例。原作者观点与我们的推断必须分栏。不复制整章到技能正文。
6. 主动收集/阅读后必须交付`learning-feedback-<日期>.md`及简短用户反馈：逐项列来源/取得状态、实际阅读范围、原意与操作推导、写入或强化的规则ID及插件版本、行为验证结果、未取得/未读内容和下一步。页面403、只读搜索片段或未核视频要明确标注；不编时间戳，不把索引当全书已读。用户明确要求融入插件时按拥有源码的更新流程修改规则并安装，私人全文不进入发布包。
7. 材料内容变化会使哈希校验失败，需要重新登记和阅读。不能宣称上传或登记等于永久训练，也不能以规则数量证明投资效果。[第一批规则](../berkshire-team/references/learned-principles.md)展示已有转化及阅读边界；后续按实际材料增补。

书籍原则作为研究问题生成器，不能覆盖当前事实、用户授权或触发交易/发信。不要未经允许将私人书籍、批注或持仓发送外部服务。
