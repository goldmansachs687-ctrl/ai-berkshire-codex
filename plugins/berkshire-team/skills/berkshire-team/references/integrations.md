# 可选能力路由

此插件自带基础研究规范；下面能力是按需适配，不是已安装或有权限的保证。不要复制另一插件的整套指令，也不要硬编码用户机器路径或虚构工具名。先从本轮技能目录和工具清单发现，按该技能路径/提供商指引读取后再用。某能力不可用时记录，使用现有授权替代。

| 本次缺口 | 优先检查 | 接口产物与边界 |
| --- | --- | --- |
| 完整公司研究的分析与表达补强 | 已启用AIVA的 investment-memo-craft，见[联合模式](joint-mode.md) | 主插件唯一调度，实际读AIVA原模块并记录应用；共用四角色、证据和模型，不启动第二队或放宽核验 |
| 公司概况、行情、多年财务、机构评级 | 已连接的[长桥接入](longbridge.md) | 当前会话原生MCP工具取数；随包规范化器保留年度/季度、币种、原字段及定位；评级不等于研报全文，不读取账户资料 |
| 公司基本情况、发展历史和重大事件 | [公司信息模块](company-info.md)：用现有联网工具直接读取 Wiki 正文及引用 | 不需要额外 Wiki 插件；保留阅读章节/日期，当前管理层与控制权按需补官方披露 |
| 美股基本财务概况 | 已授权财务工具，或直接读取公开券商/财经三表页面 | 不要求额外安装或账户；不可读时换来源，核对期间、单位、债务口径与最新披露；细节见[公司信息模块](company-info.md) |
| 中国市场行情、港股财务 | 本插件[AKShare适配器](local-market-data.md) | 通过工作区专用Python环境调用；保存原始行、参数与上游，核实币种和历史更正，不宣称独立双源 |
| SEC原始申报、申报正文、XBRL三表 | 本插件[EdgarTools适配器](local-market-data.md) | 使用真实SEC身份，按申报日截止；CIK/accession/原文链接可追溯；不替代港交所披露 |
| 美股实际与预期比较、EPS/收入一致预期修正 | 本插件[财报与预期适配器](us-earnings.md) | 读取当天Yahoo快照；保留期间、币种、EPS口径和失败状态；市场预期与公司事实分开，不算独立双源、不提供历史回填 |
| 财报、管理层电话会、演示 | Quartr可调用工具 | 验证公司、证券和期间；先读provider guide。数字优先财报/结构化财务；电话会支持管理层陈述，不能证明陈述属实 |
| 数据商价格/财务 | Financial Datasets或当前可用数据商 | 先检查市场覆盖、日期、授权；不能假设港股或ADR完全等价 |
| 估值方法选择与本地计算 | [估值工具层](valuation-tools.md)：company-valuation / FinanceToolkit | 实际读取技能、复用工作区专用解释器；保留现金桥及独立复算，不引入固定混合权重 |
| 多年三表口径混乱 | Public Equity Investing的financials-normalizer | 读取实际技能；输出标准化数据与source IDs，不重新改写主任务 |
| 可比倍数、现金流估值或可修改模型 | Public Equity Investing的comps-valuation / dcf-model-builder，确需时three-statement-model-builder | 按[估值工具层](valuation-tools.md)实际执行、保存工作簿与来源映射；不重复完整团队，按用户结构交付 |
| 并购、交易拆分、私有化与收购融资 | Investment Banking相应交易模块 | 必须符合真实交易场景；少数股权价值、控制权溢价与协同/融资假设分开，不当外部投行研报 |
| 模型来源/公式检查 | Public Equity Investing的model-audit-tieout | 输出具体问题、位置、影响和未决项；不以公式通过代表假设成立 |
| 结论超出证据、数据质量 | Data的validate-data / analyze-data-quality | 在主流程中做适度复核；用户明确全面审计才扩大深度 |
| 用户提供PDF、EPUB或文档 | PDF/文档技能或已授权提取工具 | 保留页码/章节；OCR标识与抽查；不把文件名当读过 |
| 原有价值投资技能 | management-deep-dive / thesis-drift / thesis-tracker | 只在需要纵深或前后变化时使用；不因名称相似启动重复团队 |

集成优先级：用户具体口径 > 本次原始证据与证券事实 > 已明确的分析定义。发现两个skill规则冲突时在适用范围内选更符合任务的规则并记录；不要静默平均。原始公告优先于聚合平台，固定ROE/毛利率/PE筛选值不得跨行业机械使用。

执行记录写明：能力、是否实际调用、来源/结果、失败或缺口。可用入口不等于已连接；安装不等于数据授权；适配规则不等于已完成生产环境联调。不要为调用外部技能绕过其显式入口要求。
