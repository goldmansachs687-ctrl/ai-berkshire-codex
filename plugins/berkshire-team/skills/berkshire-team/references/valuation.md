# 估值与现金桥

进入估值时按[估值工具层](valuation-tools.md)选择company-valuation、FinanceToolkit或专业建模模块；使用同一证据和预测，记录实际执行。下列现金和资本桥约束仍优先，外部默认参数/混合权重不覆盖它们。

## 盈利到股东现金

逐项记录：IFRS归母 → 投资/一次性调整 → SBC经济成本 → 子公司/联营及少数股东边界 → 折旧摊销与真实再投资 → 营运资本及净新增预付款 → 内容/租赁/利息 → 可分配现金近似。每项附原数、期间、单位、调整理由及是否已在别处扣过。

不要把经营现金流减全部capex机械称为FCFE。现金流分类、融资变化、非控股股东和股份支付必须明确。维护/扩张capex拆不出时给区间或承认不能可靠估计；预付款交付不再扣同一现金。设备经济更新可与账面折旧不同，不能无证据假设差额永久为零。

SBC费用和股份稀释避免重复惩罚：区分历史已授奖励的摊薄、未来持续员工报酬、用于抵消稀释的回购；如使用保守代理，明确近似范围而非声称精确所有者收益。

资本承诺记录余额、支付时程、取消条款、与预付/未来成本重叠、收益覆盖。缺期限不把全部当即期净债务；缺收益证据也不能忽略未来现金约束。发债同时增加现金和债务，旧资产负债表不能当最新余额。

## 方法与交叉检验

- FCFF配同币种WACC、净债务/非经营资产/少数股东桥；FCFE配股权成本。长期增长小于折现率，终值依赖和再投资可持续性显式说明。
- 整体归母PE已含投资收益/利息时不再全额加投资资产与现金；SOTP先分离相关盈利，避免子公司或联营双算。
- PE须解释盈利口径、增长、现金转换、再投资和要求回报，优先反向估值及适当同行/历史口径对照。证据不足可不选点倍数。
- 熊/基准/牛的盈利、增长、资本强度、终值或倍数分别列明；不编概率。至少做一个“盈利尚可但现金更差”的压力情景。
- 非金融企业在证据允许时用现金法交叉盈利法；金融企业按监管资本、分红能力、资产质量选择方法，不能强套工业企业DCF。
- 安全边际和上涨空间分别计算；“七折”只能是明确研究假设，不能成为所有公司的固定建议。熊情景不是最大亏损保证。

模型输出包括反向隐含预期、关键敏感性、改变结论所需证据、无法识别的参数。股息、回购与每股增厚不重复计收益。代码算术正确与经济假设成立分别给结论。
