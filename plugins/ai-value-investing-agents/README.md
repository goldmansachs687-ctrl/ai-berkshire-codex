# AI Value Investing Agents · Fernando分支

独立本地插件，来自 https://github.com/FernandoAbishai/ai-value-investing-agents ，上游1.2.0，本地插件1.2.1。

选择本插件后使用 aiva 入口，默认中文、服从当前工作区用户报告顺序。完整公司研究默认转交原伯克希尔2.2.4或后续兼容版本的联合模式；共享一支团队和一套底稿，把本包投资报告标准用于分析及表达。说“只用AIVA”可使用独立工作流，专项任务保持原范围。主插件不可用时明确未联合，不自动安装。保留22个上游工作流和本地 aiva 入口，公开版的调整见 [UPSTREAM.json](UPSTREAM.json)。

本插件显式选择后使用，不替换原AI伯克希尔定制版、全局skills或用户偏好。原始英文分支的局限仍然存在：例如部分步骤使用Claude专用权限检查，运行时应按aiva入口映射；部分模块可能需要其声明的可选依赖，不能因安装成功而认定全部在线抓取可用。

来源提交与本地适配范围见UPSTREAM.json；原始源码可从上游仓库取得。安装阶段不启动公司研究。
